- 截止日期：2026-10-25

## 维护约定
- 新增论文或工具：先在 `sources.md` 登记来源和核实状态，再在对应矩阵表加行，两处编号必须一致。
- 预印本必须标注“预印本，未确认正式发表”。
- 证据强度升级（如预印本正式发表）：更新 `sources.md` 状态，并在 commit message 中注明。
- 矩阵表按“类型/成熟度”排序。
