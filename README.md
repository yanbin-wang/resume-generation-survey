## 两方向怎么区分

| | 生成 | 筛选 |
|---|---|---|
| 谁用 | 求职者自己 | HR / 招聘团队 |
| 输入 | 自己的简历 + 目标 JD | 一批候选人的简历 + 一个 JD |
| 输出 | 一份定制简历 | 一份排序 / 打分结果 |
| 核心技术 | LLM 改写、RAG 组装、幻觉控制 | 匹配打分、排序、偏见与效度审计 |
| 成熟度 | 工程侧比学术侧成熟 | 学术侧比工程侧成熟，且已有正式论文 |
